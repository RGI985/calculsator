# Calculator

A lightweight, responsive calculator built with plain HTML, CSS, and JavaScript. It runs directly in a web browser and does not require a framework, build step, or external dependencies.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers, percentage, sign toggle, and delete
- Keyboard support: number keys, `+`, `-`, `*`, `/`, `.`, Enter, Backspace, and Escape
- Responsive dark interface with accessible labels

## Run

Open [index.html](index.html) in any modern web browser. No installation is required.

## Error handling

Dividing by zero displays **“Cannot divide by zero”** instead of a generic error. Press a number or use **AC** to continue calculating.
